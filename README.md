# Prompt-Powered Kickstart: AI Capstone (Rust)

This repository is the Rust capstone for the Moringa AI course.

## Project Goal

Create a beginner-friendly toolkit demonstrating a minimal Rust Warp web server and documenting the AI prompt journal used to learn and build it.

## Quick Start

1. Install Rust (rustup)
2. Build and run:

```bash
cd Capstone/ai_capstone_rust
cargo run
```

Open http://127.0.0.1:3000/ in your browser.

## What this repo contains

- `src/main.rs` — minimal Warp server (handles `/` and `/hello`)
- `AI_PROMPT_JOURNAL.md` — placeholder for prompts and reflections
